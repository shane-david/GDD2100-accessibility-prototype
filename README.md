# Waterside Quest

## Overview
Waterside Quest is a simple fishing game developed in Unity to showcase accessibility features. v1.0.0 is the base build of the game. It supports keyboard/controller input and allows the player to simply repeat the game loop of cast->lull->catch. 

## Features
- Keyboard/Controller input
- Basic UI
- Finished Game Loop
- Input randomizer system 

## Future Additions
- Finish accessibility features: Narrator, one hand mode, difficulty...
- Adjust UI scaling
- Inventory/Rewards for catching
- Higher contrasts UI/graphics
- More descriptive/immersive sounds
